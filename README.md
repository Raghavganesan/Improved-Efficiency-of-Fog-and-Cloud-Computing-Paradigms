# Improved-Efficiency-of-Fog-and-Cloud-Computing-Paradigms

Overview

This repository contains the research paper "Improved Efficiency of Fog and Cloud Computing Paradigms", which explores a two-tier Fog and Cloud computing architecture for optimized energy management in smart grids. The study focuses on reducing latency, congestion, and energy consumption, enabling real-time decision-making at the edge.

Publication Details
📌 Published in: 2024 2nd International Conference on Advancements and Key Challenges in Green Energy and Computing (AKGEC)
📌 Indexed in: IEEE Xplore
📌 DOI: 10.1109/AKGEC62572.2024.10869278
📌 Conference Date: 21-23 November 2024
📌 Conference Location: Ghaziabad, India

Abstract
In this research, we propose a novel Fog computing architecture that bridges the gap between edge devices and Cloud computing. By leveraging a two-tier approach, our system preprocesses and filters sensor data in the Fog layer, significantly reducing network congestion and execution time. Simulations using iFogSim show a 98.7% latency reduction over Cloud-only models, making our approach more efficient and scalable for smart grids.
